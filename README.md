# Rainfall-Based Flood Risk Visualization

This project visualizes year-wise rainfall trends for coastal Tamil Nadu,
with a focus on Chennai.

A high rainfall anomaly threshold is defined as 125% of the historical
average rainfall. Years exceeding this threshold are highlighted to
indicate periods of elevated flood risk context.

This project focuses on visualization-driven risk indication rather than
event-level flood prediction.

## Tools Used
- Python
- Pandas
- Matplotlib
